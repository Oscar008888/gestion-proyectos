# Sistema de Gestión de Proyectos

## 📋 Descripción
Aplicación de consola para gestionar proyectos estilo Trello, con sistema de registro e inicio de sesión de usuarios. Permite crear y organizar proyectos, listas y tareas.

## 🛠️ Tecnologías utilizadas
- **Python 3**
- **Peewee ORM** — para la base de datos
- **SQLite** — base de datos local
- **bcrypt** — para encriptar contraseñas
- **maskpass** — para ocultar contraseñas al escribir
